# Citation-safeguard evaluation

The test suite uses synthetic passages and fake search/fetch adapters; it does not claim web-research accuracy. It checks that:

- source IDs are generated by the application from retrieved records;
- each report finding is an exact excerpt from the cited evidence record;
- unknown IDs and text not present in the cited evidence fail the audit;
- model-assisted mode can change only the bounded search plan, never report findings or citations;
- originating query attribution survives multi-query result interleaving.

Run `python -m unittest discover -s tests -v` from the project root. The result is a software guardrail check, not an entailment or factuality benchmark. No sources, claims, or model scores are fabricated for this evaluation.
